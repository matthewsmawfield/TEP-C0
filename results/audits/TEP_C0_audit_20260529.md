# TEP-C0 Pipeline Audit Report
**Date:** 2026-05-29
**Status:** CRITICAL ACTION REQUIRED

## Executive Summary
A comprehensive scan of the TEP-C0 pipeline reveals severe methodological flaws that compromise the integrity of the research. Chief among these are the use of fabricated data for the SZ/SGL screening fits, hardcoded "rubber stamp" validation gates, and unseeded stochastic processes. These directly violate the core principle of rigorous, reproducible, unassailable data analysis. 

The pipeline cannot be considered research-grade until all of the following issues are resolved.

## Detailed Findings

### 1. Fabricated SZ/SGL $\eta$ Data (CRITICAL)
**Location:** `scripts/steps/step_04_06_screening_fit.py:107-123`
**Issue:** The script generates synthetic distance-duality ($\eta$) values using `np.random.randn()` centered on hand-picked means (0.35, 0.38). This propagates fabricated screening constraints into the core theory derivation.
**Remediation:** Remove all synthetic data generation. The pipeline must either compute real $\eta$ values from the raw catalogs or cleanly omit these probes/fail loudly.

### 2. Null-Injection Test Rubber Stamp (CRITICAL)
**Location:** `scripts/steps/step_02_03_physics_implementation.py:436-468`
**Issue:** The `_run_null_injection_tests` function hardcodes `epsilon_T_recovered = 0.0` and `tep_mock_pass = True`, ensuring the validation gate always passes regardless of actual pipeline performance.
**Remediation:** Replace this mock function. It should read the actual results from the true null-injection test performed in `step_03_01_three_model_comparison.py`.

### 3. Placeholders Marked as Completed (CRITICAL)
**Location:** `scripts/steps/step_08_08_diagnostic_plots.py:31-47`
**Issue:** The script generates text files masquerading as images (`.png`), writes "(Placeholder)", and marks the step as `completed`. This is highly misleading.
**Remediation:** The step must `raise NotImplementedError` and fail loudly until real Matplotlib plotting logic is implemented.

### 4. Unseeded Stochastic Operations (HIGH)
**Location:** `scripts/steps/step_03_01_three_model_comparison.py:1195-1221`
**Issue:** The 200-trial Monte Carlo for the false-positive rate uses global `np.random`, rendering the reported `false_positive_rate` un-reproducible.
**Remediation:** Implement deterministic RNG using `rng = np.random.default_rng(int(os.getenv("TEP_NULL_SEED", "42")))`.

### 5. Weak Validation Gates (HIGH)
**Location:** `scripts/steps/step_03_01_three_model_comparison.py:1188-1193`
**Issue:** The deterministic null-injection test passes if $\Delta \log \mathcal{L} < 2.0$. Given that the nested model can freely match the baseline, this gate is too loose to prove the pipeline doesn't hallucinate TEP.
**Remediation:** Tighten the condition to `abs(delta_logL) < 0.5`.

### 6. Magic Numbers Driving Theory (MEDIUM)
**Location:** `scripts/steps/step_02_02_theory_derivation.py:92-116`
**Issue:** Lagrangian coefficients and inputs are hardcoded "preliminary" values, yet the script hardcodes `validation.theory_consistent_with_data = True`.
**Remediation:** Remove the hardcoded validation pass. Ensure the step correctly reports its `research_grade` status as False until proper empirical calibration is established.

### 7. Silent Data Exclusions (MEDIUM)
**Location:** `scripts/steps/step_02_03_physics_implementation.py:611-614`
**Issue:** SNe with $z > 1.5$ are silently dropped from the Pantheon+ validation test without logging or justification.
**Remediation:** Record the number of excluded SNe (`n_excluded_z_gt_1_5`) and embed the justification natively in the output payload.

### 8. Stale Pipeline Audit Script (MEDIUM)
**Location:** `scripts/utils/pipeline_audit.py`
**Issue:** The script checks for outdated JSON artifacts (e.g., `step_022_three_model_comparison.json`) resulting in false-negative audit failures.
**Remediation:** Update the step mappings to reflect the current active pipeline architecture.
